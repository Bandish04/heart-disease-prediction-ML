# Heart Disease Prediction Using Machine Learning

My first Machine Learning project, built using Python and the K-Nearest Neighbors (KNN) algorithm.

## Features
- Predicts the likelihood of heart disease based on input data
- Interactive web interface built with Streamlit
- Trained machine learning model

## Technologies
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Run Locally

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```

## Disclaimer
This project is for educational purposes only and is not intended for medical diagnosis.
